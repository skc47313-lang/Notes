NOTES BAZAR — PREMIUM UI UPDATE

Included: original project files plus premium.css and premium.js.

Changes in this update:
- Apple-inspired clean header, search area, spacing, cards and subtle motion.
- More compact hamburger drawer and more organized menu spacing.
- Profile/dialog visual polish while keeping the existing profile/account logic.
- Quick Options layout: two cards per row on mobile (up to 600px), two on tablet, three on desktop.
- Desktop Mode toggle in the hamburger menu; preference is saved in this browser. On small screens it provides a wider desktop-style layout with horizontal scrolling.
- Premium admin dashboard shell, tabs, inputs and overview/upload cards. Existing admin feature IDs and inline handlers are retained.

HOW TO USE
1. Keep a backup of your current Notes Bazar folder.
2. Extract this ZIP.
3. Upload/deploy the contents of the inner project folder together, keeping all files in the same directory.
4. Test the home page, login/profile, save/download, notifications, upload, admin dashboard and mobile layout before publishing.

This is a static HTML/CSS/JavaScript project. The UI additions are designed to be additive; test all existing Firebase-backed workflows in your own environment before replacing the live site.
